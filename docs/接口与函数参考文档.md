## 3. 接口逐项说明

### 3.1 `GET /health`

作用：

- 检查服务是否启动成功

### 3.2 `POST /conversations`

作用：

- 创建一个新会话

请求体：

```json
{
  "topic": "AI Agent Tool Use",
  "title": "Agent Research"
}
```

后端函数：

- `ProductApiHandlers.create_conversation`
- `ConversationService.create_conversation`

### 3.3 `GET /conversations`

作用：

- 获取历史会话列表

查询参数：

- `limit`：可选

后端函数：

- `ProductApiHandlers.list_conversations`
- `ConversationService.list_conversations`

### 3.4 `GET /conversations/{conversation_id}`

作用：

- 获取单个会话详情
- 返回基础信息和 `message_count`

后端函数：

- `ProductApiHandlers.get_conversation`
- `ConversationService.get_conversation`
- `MessageService.list_messages`

### 3.5 `GET /conversations/{conversation_id}/messages`

作用：

- 获取某个会话下的消息列表

后端函数：

- `ProductApiHandlers.list_messages`
- `MessageService.list_messages`

### 3.6 `POST /conversations/{conversation_id}/messages`

作用：

- 在指定会话中写入一条消息

请求体：

```json
{
  "role": "user",
  "content": "Focus on evaluation benchmarks",
  "metadata": {
    "source": "manual"
  }
}
```

后端函数：

- `ProductApiHandlers.create_message`
- `MessageService.create_message`

### 3.7 `POST /conversations/continue`

作用：

- 在已有会话上继续追问
- 写入用户消息
- 返回最近上下文预览
- 可选创建 follow-up task

请求体：

```json
{
  "conversation_id": "conv_xxx",
  "content": "Only focus on benchmark and evaluation papers",
  "focus": "benchmark evaluation",
  "create_follow_up_task": true,
  "mode": "balanced"
}
```

当前返回重点：

- `message_id`
- `context_preview`
- `follow_up_task`

后端函数：

- `ProductApiHandlers.continue_conversation`
- `ConversationService.get_conversation`
- `MessageService.create_message`
- `MessageService.get_recent_context`
- `ResearchService.create_follow_up_task`

### 3.8 `POST /research/tasks`

作用：

- 创建一条研究任务记录

请求体：

```json
{
  "conversation_id": "conv_xxx",
  "topic": "AI Agent Tool Use",
  "mode": "default"
}
```

约束：

- `conversation_id` 必须存在
- `mode` 仅支持 `default / fast / balanced`

后端函数：

- `ProductApiHandlers.create_research_task`
- `ResearchService.create_task`

### 3.9 `GET /research/tasks`

作用：

- 获取研究任务列表

查询参数：

- `conversation_id`：可选
- `limit`：可选

后端函数：

- `ProductApiHandlers.list_research_tasks`
- `ResearchService.list_tasks`

### 3.10 `GET /research/tasks/{task_id}`

作用：

- 获取单个任务状态与元数据

后端函数：

- `ProductApiHandlers.get_research_task`
- `ResearchService.get_task`

### 3.11 `POST /research/tasks/{task_id}/run`

作用：

- 运行指定研究任务

当前行为：

- 任务开始前设为 `running`
- 成功后设为 `completed`
- 失败后设为 `failed`
- 成功/失败后都会回写 assistant 消息

后端函数：

- `ProductApiHandlers.run_research_task`
- `ResearchService.get_task`
- `ResearchService.run_task`

### 3.12 `GET /research/tasks/{task_id}/workspace`

作用：

- 获取任务对应的 workspace 快照

返回主体：

- `task_id`
- `topic`
- `summary`
- `papers`
- `taxonomy`
- `graph_edges`
- `gaps`
- `ideas`
- `alignment_score`
- `trace`

后端函数：

- `ProductApiHandlers.get_workspace`
- `WorkspaceService.get_workspace_snapshot`

### 3.13 `GET /tools`

作用：

- 获取工具列表

后端函数：

- `ProductApiHandlers.list_tools`
- `ToolService.list_tools`

### 3.14 `PATCH /tools/{tool_id}`

作用：

- 更新工具启用状态与配置

后端函数：

- `ProductApiHandlers.update_tool`
- `ToolService.update_tool_enabled`

### 3.15 `GET /skills`

作用：

- 获取 skills 列表

后端函数：

- `ProductApiHandlers.list_skills`
- `SkillService.list_skills`

当前版本已经不再只是“有一堆空接口”，而是：

**会话 -> 消息 -> follow-up task -> 任务运行 -> workspace 返回**

这条链路已经是真实可用的。
