# 字段字典

更新时间：2026-06-15

本文统一当前核心字段的业务语义。接口的精确结构以 `schemas/` 和 `ui/src/types/api.ts` 为准。

## 1. 会话与任务

### `Conversation`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `conversation_id` | `str` | 长期研究会话 ID |
| `title` | `str` | 用户可见研究名称 |
| `topic` | `str` | 会话主研究主题 |
| `latest_task_id` | `Optional[str]` | 最近任务 |
| `message_ids` | `List[str]` | 关联消息 |
| `created_at` / `updated_at` | `datetime` | 创建和更新时间 |

### `MessageRecord`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `message_id` | `str` | 消息 ID |
| `conversation_id` | `str` | 所属研究 |
| `role` | `str` | `user / assistant / system` |
| `content` | `str` | 消息正文 |
| `metadata` | `Dict[str, Any]` | task 链接、来源和扩展信息 |
| `created_at` | `datetime` | 消息时间 |

### `ResearchTask`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `task_id` | `str` | 单次研究任务 ID |
| `conversation_id` | `str` | 所属长期研究 |
| `topic` | `str` | 本轮研究主题或追问 |
| `status` | `str` | `created / running / completed / failed` |
| `trigger_message_id` | `Optional[str]` | 触发本轮的消息 |
| `mode` | `str` | `default / fast / balanced` |
| `research_mode` | `str` | `hybrid / imported_only / search_only` |
| `knowledge_scope` | `str` | `none / conversation_only / shared` |
| `selected_skill_ids` | `List[str]` | 本轮选中的 Skill，已实现并持久化 |

## 2. 论文字段

### `WorkspacePaperView`

| 字段 | 含义 |
| --- | --- |
| `paper_id` | 论文稳定标识 |
| `title` | 论文标题 |
| `publish_date` | 发布日期 |
| `source` | ArXiv、用户上传等数据来源 |
| `taxonomy_category` | 当前分类 |
| `citation_count` | 引用数；仅在 `citation_count_known=true` 时可视为已获取 |
| `citation_count_known` | 是否成功获得引用数 |
| `citation_source` | 引用数来源 |
| `url` | 论文外链 |
| `is_new_this_round` | 是否为本轮新增 |
| `relevance_score` | 与当前研究的相关性分数 |
| `relevance_tier` | 相关性等级 |
| `relevance_reasons` | 进入当前层级的理由 |
| `paper_pool_status` | 核心分析或扩展候选等池状态 |
| `document_id` | 对应知识文档 ID |
| `origin` | `system_search / user_upload / user_import` 等来源身份 |

注意：

- `citation_count=0` 不等于零引用，必须同时检查 `citation_count_known`。
- `papers` 是可展示论文集合，真正参与本轮结构化分析的论文由 `analysis_paper_ids` 标识。

| `graph_edges` | 论文关系 |
| `gaps` | 研究空白 |
| `ideas` | 研究建议 |
| `alignment_score` | 结果与研究主题的对齐分数 |
| `evidence_status` | 当前证据是否充足及论文构成 |

| `inherited_context` | 本轮继承的历史研究上下文 |
| `working_memory` | conversation 级工作记忆 |

## 4. Taxonomy

常用 branch 字段：

| 字段 | 含义 |
| --- | --- |
| `branch_id` | 分支 ID |
| `name` | 分支名称 |
| `description` | 分支说明 |
| `required_concepts` | 分支应覆盖的概念 |
| `paper_count` | 被归入分支的论文数 |
| `gap_count` | 被归入分支的研究空白数 |
| `coverage` | 当前论文对该分支的证据覆盖度 |
| `matched_paper_ids` | 实际匹配论文 |
| `matched_gap_ids` | 实际匹配空白 |
| `evidence_tier` | 分支证据等级 |
| `branch_confidence` | 分支判定置信度 |

`coverage` 表示证据覆盖，不表示研究领域本身已经完整。

## 5. 研究关系图谱

### `WorkspaceGraphEdgeView`

| 字段 | 含义 |
| --- | --- |
| `source` | 起点论文 ID |
| `target` | 终点论文 ID |
| `relationship` | `citation / improves / extension / compares / related` 等 |
| `reasoning` | 面向用户的关系解释 |
| `provenance` | 关系来源，例如元数据、正文或模型判定 |
| `confidence` | 关系置信度 |
| `evidence_level` | 证据等级 |
| `evidence` | 主要证据说明 |
| `evidence_snippets` | 支撑关系的文本片段 |
| `evidence_details` | 更结构化的证据详情 |

规则：

- `related` 只表示主题关联，不等于演进。
- `citation` 应来自可追溯引用元数据。
- `improves / extension / compares` 需要更强文本证据。
- 前端不得自行创造边或升级关系类型。

## 6. 研究空白与建议

`WorkspaceGapView` 和 `WorkspaceIdeaView` 共享以下结论证据字段：

| 字段 | 含义 |
| --- | --- |
| `supporting_paper_ids` | 支撑该结论的当前分析池论文 |
| `evidence_level` | `direct / indirect / exploratory` |
| `evidence_reason` | 为什么被判定为该等级 |

等级语义：

- `direct`：明确直接证据。
- `indirect`：与论文相关，但尚未完成全文级结论核验。
- `exploratory`：无合格论文绑定，应视为待验证假设。

约束：

**`supporting_paper_ids` 必须属于当前分析论文池，不能直接引用未进入本轮分析的共享知识。**

## 9. 对象关系

- `Conversation` 管长期研究。
- `MessageRecord` 管多轮交流。
- `ResearchTask` 管一次首轮生成或追问。
- `WorkspaceSnapshotResponse` 管一次结果或 conversation 总览。
- `KnowledgeDocument` 管可检索知识。
- `ConversationResearchPaper` 管当前研究拥有的论文资产。
- `SkillDescriptor` 管可选择的研究能力描述。

**taxonomy、graph、gaps 和 ideas 都是后端基于证据生成的 workspace 结果，前端只负责呈现与解释。**
