## 3. 演示建议

答辩演示优先选择稳定主链：

1. 新建研究。
2. 可选导入 PDF。
3. 选择 `hybrid` 和合适知识范围。
4. 生成首轮结果。
5. 展示 Overview / Evidence / Map / Context / Run。
6. 发送带年份、方法或场景约束的追问。
7. 展示本次结果与本研究总览的差异。

## 4. 当前产品一句话

Product Agent 是一个证据驱动的科研调研 Agent：它把系统检索论文、用户上传 PDF、共享知识和多轮追问组织成可追溯的研究工作台，帮助用户判断“该读什么、已有路线是什么、还缺什么、下一步怎么做”。
