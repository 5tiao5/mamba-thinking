# 任务清单

这份文档只做一件事：

**把当前仓库里哪些功能已经真实可用、哪些还待实现或待优化、下一阶段最适合谁来接手，写清楚。**

---

## 1. 当前阶段结论

`product_agent/` 现在已经不是“只有骨架”的状态，而是已经具备：

- 可运行的 FastAPI 后端
- 可运行的 React + Vite 前端
- 默认可用的 SQLite 持久化
- 会话、消息、任务、workspace 的最小主链路
- follow-up task 链路
- 历史查询接口
- 基本可读的 workspace 页面

所以当前阶段的定位是：

**工程基线已完成，可以进入“多人并行补产品体验与核心能力”的下一阶段开发。**

## 3. 当前仍待实现或待优化的内容

下面这些不是“完全没有”，而是“现在做得还不够，值得作为下一阶段重点”。

### 3.1 多轮会话体验还不够自然

现状：

- assistant 消息已经会回写
- 但内容更像“任务执行结果摘要”
- 还不够像一个真正连续对话式的研究助手

重点优化方向：

- 把 assistant 消息写得更像针对追问的回答
- 让消息、task、workspace 的对应关系在前端更清楚

涉及文件：

- [message_service.py](/D:/iteration_two-master/iteration_two-master/product_agent/services/message_service.py)
- [ConversationPage.tsx](/D:/iteration_two-master/iteration_two-master/product_agent/ui/src/pages/ConversationPage.tsx)
- [HistoryPage.tsx](/D:/iteration_two-master/iteration_two-master/product_agent/ui/src/pages/HistoryPage.tsx)

### 3.2 taxonomy 生成与覆盖判定仍需继续优化

现状：

- 这轮已经引入了新的 grounding 服务，修复了“分支全未覆盖”的大坑
- 但 taxonomy 本身仍偏理想化，和真实检索证据的耦合还可以更强

已新增：

- [taxonomy_grounding_service.py](/D:/iteration_two-master/iteration_two-master/product_agent/services/taxonomy_grounding_service.py)

下一步优化方向：

- 让 taxonomy 生成本身更 evidence-aware
- 减少“先生成一个很全的 taxonomy，再发现大部分没证据”的情况

### 3.3 搜索质量仍值得优化

现状：

- searcher 已经能跑
- 但仍可能搜到“沾边但不够准”的论文
- fallback 论文仍然存在

涉及文件：

- [searcher.py](/D:/iteration_two-master/iteration_two-master/product_agent/research_agent/nodes/searcher.py)
- [pipeline_utils.py](/D:/iteration_two-master/iteration_two-master/pipeline_utils.py)

下一步优化方向：

- 提高候选论文筛选质量
- 降低 fallback 触发概率

### 3.4 RAG / knowledge 还没真正接进主链路

现状：

- `KnowledgeService` 骨架在
- SQLite 持久化也有了
- 但用户还感受不到“这个系统正在用知识增强回答”

涉及文件：

- [knowledge_service.py](/D:/iteration_two-master/iteration_two-master/product_agent/services/knowledge_service.py)

下一步优化方向：

- 支持导入知识或论文
- 在 `continue_conversation` 或 `run_task` 前做 retrieval
- 用已有知识减少 fallback

### 3.5 workspace 仍需继续打磨

现状：

- taxonomy 与 graph 已图形化
- 但仍有一些地方偏工程调试感

重点优化方向：

- taxonomy 文案更自然
- graph 交互更清晰
- fallback 结果的展示和解释更产品化

涉及文件：

- [WorkspacePage.tsx](/D:/iteration_two-master/iteration_two-master/product_agent/ui/src/pages/WorkspacePage.tsx)
- [WorkspaceTaxonomyMap.tsx](/D:/iteration_two-master/iteration_two-master/product_agent/ui/src/components/workspace/WorkspaceTaxonomyMap.tsx)
- [WorkspaceGraphCanvas.tsx](/D:/iteration_two-master/iteration_two-master/product_agent/ui/src/components/workspace/WorkspaceGraphCanvas.tsx)

### 3.6 工程化收尾仍未完成

现状：

- 本地测试和构建都能过
- 但 CI/CD、部署链路还没正式接起来

下一步方向：

- GitLab Runner 跑 CI
- GitHub mirror + Vercel / Render 做自动部署

### 4.2 后端组

现在最适合直接接手的是：

1. 搜索质量优化
2. taxonomy evidence-aware 继续增强
3. knowledge / RAG 最小接入
4. 会话-任务-workspace 链路体验增强

为什么适合：

- 主链路已经成型
- 现在改动是增强与打磨，不是大推倒

1. 不要随意改 API 字段名
2. 不要让 handler 直接碰 repository
