# 前后端实现任务清单

## 1. 文档目的

本文档用于把当前架构骨架转换为可以直接分配给组员的实现任务。

建议使用方式：

- 组长按优先级分配任务
- 组员开发前先阅读对应代码入口与参考文档
- 每个任务尽量以“接口稳定 + 小步提交”的方式推进

## 2. 前端任务清单

建议前端 2 人分工。

### 前端 A：对话与会话流

目标：

- 负责用户如何“和产品交互”

任务：

1. 搭建 React + Vite 前端项目
2. 建立基础页面路由
3. 实现“新建研究会话”页面
4. 实现“多轮对话区”页面
5. 实现“历史会话列表”页面
6. 对接以下接口：
   - `POST /conversations`
   - `POST /conversations/continue`
   - `POST /research/tasks`
7. 设计消息气泡、输入框、发送逻辑
8. 增加任务状态展示，例如：
   - created
   - running
   - completed

主要参考：

- [fastapi_app.py](/D:/iteration_two-master/iteration_two-master/product_agent/api/fastapi_app.py)
- [API_FUNCTION_REFERENCE.md](/D:/iteration_two-master/iteration_two-master/product_agent/docs/API_FUNCTION_REFERENCE.md)

### 前端 B：研究工作台

目标：

- 负责用户如何“看懂分析结果”

任务：

1. 实现 workspace 主页面
2. 实现以下区域：
   - 论文列表
   - taxonomy 面板
   - graph 面板
   - gap 面板
   - research ideas 面板
3. 对接以下接口：
   - `POST /research/tasks/{task_id}/run`
   - `GET /research/tasks/{task_id}/workspace`
   - `GET /tools`
   - `GET /skills`
4. 设计“分析中 / 已完成 / 出错”状态视图
5. 设计工具配置与 skill 列表展示页

主要参考：

- [schemas/research.py](/D:/iteration_two-master/iteration_two-master/product_agent/schemas/research.py)
- [schemas/tooling.py](/D:/iteration_two-master/iteration_two-master/product_agent/schemas/tooling.py)

## 5. 优先级建议

### 第一优先级

- React 项目起步
- FastAPI 服务能跑起来
- 新建会话 -> 创建任务 -> 运行任务 -> 获取 workspace 这条主链路打通

### 第二优先级

- workspace 展示更完整
- tools / skills 设置页
- 多轮对话入口

### 第三优先级

- 共享知识
- 最小版 RAG
- 更精细的审计和对比能力
